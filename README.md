MacMonitor

**MacMonitor** is a free macOS menu bar monitoring tool developed by Carbon, designed for Macs with Apple silicon.

- **Menu Bar Monitoring:** View CPU and memory usage directly in the menu bar, with customizable display modes including dual-line numbers, CPU percentage, usage bars, or icon-only mode.
- **Detailed System Monitoring:** Open the monitoring panel to view temperatures, fan speeds, disk I/O, network traffic, and power consumption for supported components, including the CPU, GPU, Neural Engine, and other hardware.
- **Multilingual Support:** Available in Simplified Chinese, English, Japanese, Korean, and French. The language can automatically follow your system settings or be selected manually.

## Download and Installation

Download the `.pkg` installer from the **Assets** section below, then double-click the downloaded file and follow the on-screen installation instructions.

### Important: macOS Security Warning

**MacMonitor is currently distributed without an Apple Developer ID signature or Apple notarization.**

As a result, when opening the installer or launching MacMonitor for the first time, macOS may display a security warning such as:

- "Apple cannot check it for malicious software."
- "macOS cannot verify that this app is free from malware."
- "The developer cannot be verified."

These warnings may appear because MacMonitor has not yet completed Apple's developer verification and notarization process. They do not necessarily indicate that the software contains malware, but they also do not guarantee that it is safe.

**If you downloaded MacMonitor from the official GitHub release and trust the source, you can manually allow it to open:**

1. Double-click the downloaded `.pkg` installer.
2. If macOS blocks the installer, dismiss the warning.
3. Open **System Settings** on your Mac.
4. Navigate to **Privacy & Security**.
5. Scroll down to the **Security** section.
6. Find the message indicating that MacMonitor was blocked, then click **Open Anyway**.
7. If prompted, enter your Mac login password or authenticate with Touch ID.
8. Confirm by clicking **Open** or **Open Anyway**, then continue the installation.

Once authorized, macOS will normally remember your decision, allowing you to open MacMonitor without repeating these steps.

**Note:** Only override this warning if you obtained the installer from a trusted source. If macOS explicitly reports that the file contains malware, is damaged, or has been tampered with, do not bypass the warning.

## Privacy and Data Security

**MacMonitor is designed with privacy in mind.**

Its primary purpose is to display hardware and system performance information directly on your Mac.

- **Local Monitoring:** Hardware metrics such as CPU usage, memory usage, temperatures, fan speeds, disk I/O, and power consumption are processed locally.
- **No Monitoring Data Uploads:** MacMonitor does not transmit the collected system performance metrics to external servers.
- **Privacy by Design:** The monitoring functionality does not require access to your personal documents, photos, passwords, or browsing history.
- **No Tracking for Monitoring:** System monitoring is intended to operate without transmitting personal activity information to third parties.

The macOS security warning described above is related to Apple's application signing and verification requirements, rather than evidence that MacMonitor is collecting or leaking personal information.

MacMonitor aims to provide a lightweight, transparent, and privacy-conscious monitoring experience.
